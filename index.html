Configuración de Arbacs

Configura dónde está Minecraft, tu perfil Forge y el repositorio de GitHub para las actualizaciones. La autenticación del juego seguirá realizándose en el launcher oficial de Microsoft/Minecraft.

La carpeta seleccionada debe ser la carpeta raíz .minecraft, no la carpeta mods. La carpeta mods se abrirá dentro de esa ubicación.
